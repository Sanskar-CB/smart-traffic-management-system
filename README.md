# 1. 🎬 Movie Recommendation System

An **end-to-end recommendation engine** combining **Content-Based Filtering** and **Collaborative Filtering (SVD)** to provide personalized movie recommendations.

## 🌟 Key Features

- 🎥 **Content-Based Filtering**
  - TF-IDF Vectorization
  - Cosine Similarity
  - Movie Metadata Processing

- ⭐ **Collaborative Filtering**
  - Singular Value Decomposition (SVD)
  - User Rating Prediction
  - Personalized Recommendations

- 🤖 **Hybrid Recommendation Capability**
  - Movie-to-Movie Recommendation
  - User-to-Movie Recommendation

## 🛠 Tech Stack

`Python` • `Scikit-learn` • `Surprise (scikit-surprise)` • `Pandas` • `NumPy`



# 2. 🛡️ AI-Based Cybersecurity Threat Detection

A **Hybrid Intrusion Detection System (IDS)** that combines **Supervised Learning** for known attacks with **Unsupervised Learning** for zero-day threat detection.

## 🌟 Key Features

- 🛡️ **Random Forest Threat Classification**
  - Detects known attack signatures
  - High classification accuracy

- 🚨 **Isolation Forest**
  - Detects unknown attacks
  - Zero-Day Threat Identification

- ⚙️ **Data Preprocessing**
  - StandardScaler
  - LabelEncoder
  - Feature Engineering

- 📡 **Live Packet Analysis**
  - Real-time network packet prediction
  - Threat probability estimation

## 🛠 Tech Stack

`Python` • `Scikit-learn` • `Random Forest` • `Isolation Forest` • `Pandas` • `Matplotlib` • `Seaborn`



# 3. 🚦 Smart Traffic Management System

An **AI-powered traffic optimization system** that dynamically controls signal timing based on real-time congestion levels.

## 🌟 Key Features

- 🚗 **Passenger Car Unit (PCU) Weighting**
  - Congestion score calculation
  - Vehicle-type prioritization

- 🚦 **Dynamic Signal Timing**
  - Adaptive green signal allocation
  - Minimum: **10 seconds**
  - Maximum: **60 seconds**

- 👁️ **Computer Vision Integration**
  - Vehicle Detection
  - Lane Monitoring
  - Traffic Density Visualization

## 🛠 Tech Stack

`Python` • `OpenCV` • `Pandas` • `NumPy` • `Matplotlib` • `Seaborn`

# ⚙️ Quick Start

